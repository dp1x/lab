# webdocs/ — External Reference Material

This directory holds **material from the web** — saved for reference while we work.
It is the external counterpart to `localdocs/` (the lab's own writing).

## Acquisition Priority

1. **Official API** (preferred — programmatic and stable)
2. **Official downloadable dataset/file**
3. **Normal public webpage**
4. **Browser automation** (browser automation only when the above are unavailable)

## Policy (authoritative version: `AGENTS.md` §Responsible Web Access)

- **Public sources only.** NASA, arXiv, official documentation, open data, papers.
- **Cite the origin.** Every file records where it came from and when it was fetched.
- **Keep files small.** Prefer text/notes over raw dumps; link instead of duplicating
  large content.
- **Never proprietary.** No personal data, no keys/tokens, nothing under license we
  can't redistribute.
- **Be conservative with browser automation** — see `AGENTS.md`. Never bypass
  CAPTCHAs, access controls, or rate limits; stop and report antibot/verification
  gates to the human.

## Search Engines

Prefer DuckDuckGo, a reputable SearXNG instance, or Startpage for general discovery.
Do not use Google/Bing for ordinary search (accessing a Google-hosted public
document/dataset as the source is fine).
